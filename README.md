## Featured Projects

### [CareerAI — AI-Powered Career Copilot Platform](https://github.com/Ujjwalrao/CareerAI)
9 integrated modules and 21 REST APIs covering resume parsing, semantic job matching, AI mock interviews, salary negotiation, and application tracking. Hybrid semantic search pipeline using pgvector + keyword matching achieving **sub-5ms retrieval latency**, with JWT auth, Google OAuth, and CI/CD via GitHub Actions.

**Stack:** FastAPI · React · PostgreSQL (pgvector) · Groq/Gemini
🔗 [Live Demo](https://career-ai-nu-roan.vercel.app/) · [GitHub](https://github.com/Ujjwalrao/CareerAI)

### [NeuroDocs AI — AI-Powered Document Intelligence Platform](https://github.com/Ujjwalrao/-neurodocs-ai)
Document intelligence platform integrating OCR, multilingual translation, ML-based classification (TF-IDF + Logistic Regression/Random Forest), and a custom FAISS-based RAG pipeline across 27+ REST APIs. Reduced image-heavy PDF sizes by up to **84%** while preserving quality; fully containerized with Docker.

**Stack:** FastAPI · FAISS · Docker · React
🔗 [Live Demo](https://neurodocs-ai.vercel.app/) · [GitHub](https://github.com/Ujjwalrao/-neurodocs-ai)

### [Detectron AI — Unified AI Detection Platform](https://github.com/Ujjwalrao/Detectron-AI)
Browser-based platform unifying 15 detection systems across fraud detection, NLP, computer vision, and network security. Implemented Multinomial Naive Bayes from scratch (**92% spam classification accuracy**) and fraud detection models achieving **99% ROC-AUC**, with TensorFlow.js for real-time client-side inference.

**Stack:** TensorFlow.js · Scikit-learn · React
🔗 [Live Demo](https://detectron-ai.vercel.app/) · [GitHub](https://github.com/Ujjwalrao/Detectron-AI)

### [FinIQ — AI-Powered Personal Finance Platform](https://github.com/Ujjwalrao/FinIQ-AI)
10 machine learning models spanning regression, classification, forecasting, recommendation, and deep learning, served through a FastAPI inference service with cached model loading (~188MB memory footprint). **97% R²** for expense prediction, **0.73 ROC-AUC** for loan approval, **1.8% MAPE** for forecasting, **86.7%** sentiment classification accuracy.

**Stack:** FastAPI · Scikit-learn · XGBoost · React
🔗 [Live Demo](https://fin-iq-ai-pi.vercel.app/) · [GitHub](https://github.com/Ujjwalrao/FinIQ-AI)
