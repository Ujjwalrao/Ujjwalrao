## 🚀 Featured Projects

<details>
<summary><b>🧭 CareerAI — AI-Powered Career Copilot Platform</b></summary>
<br/>

An end-to-end AI career platform combining deterministic scoring with semantic retrieval to remain reliable even when embedding services degrade.

| | |
|---|---|
| **Stack** | Python, FastAPI, PostgreSQL, pgvector, LLMs |
| **Scale** | Multi-module pipeline — resume parsing, job matching, negotiation engine |
| **Performance** | Hybrid keyword + semantic retrieval maintains matching under embedding-service failure |
| **Security** | Backend-enforced numeric constraints prevent LLM-generated invalid outputs |
| **Impact** | Eliminated redundant model inference calls via deterministic rule-based ATS scoring |
| **Repository** | [github.com/Ujjwalrao/CareerAI](https://github.com/Ujjwalrao/CareerAI) |
| **Live Demo** | [career-ai-nu-roan.vercel.app](https://career-ai-nu-roan.vercel.app/) |

**Engineering Highlights**
- Designed a hybrid job-matching pipeline combining deterministic keyword scoring with pgvector semantic retrieval, preserving matching quality when embedding services are unavailable.
- Added a deterministic regex-based validation layer alongside LLM-based resume extraction to improve reliability for structured fields without extra API cost.
- Replaced an LLM-based resume scoring step with a deterministic rule-based scorer, cutting a model inference call while keeping ATS feedback explainable.
- Split negotiation logic between LLM-generated conversational tone and backend-enforced numeric constraints after observing LLMs miscalculate percentage increases.

</details>
